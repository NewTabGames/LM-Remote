# LM Remote

Control [Lethal Menu](https://github.com/NewTabGames/LethalMenu) from your browser.

**Website:** https://newtabgames.github.io/LM-Remote/ ([demo](https://newtabgames.github.io/LM-Remote/?demo))

## How to use

1. Install [Lethal Menu](https://github.com/NewTabGames/LethalMenu).
2. In game, open the menu: **Settings → Remote Panel → Enable Remote**. It shows a pairing code.
3. On the website, make an account, press **Add PC** and type the code.
